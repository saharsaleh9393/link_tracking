# داشبورد فارسی Streamlit

رابط مدیریت و تحلیل در شاخه `feat/streamlit-dashboard` به بک‌اند موجود اضافه شده است. مرورگر فقط به Streamlit وصل می‌شود؛ درخواست‌های احراز‌شده به FastAPI در سمت سرور ارسال می‌شوند. نیازی به Swagger، واردکردن کلید API در مرورگر یا Power BI نیست.

## بخش‌های برنامه

- **نمای کلی:** تعداد لینک‌های حذف‌نشده، کمپین‌های بایگانی‌نشده، کلیک‌های هفت روز اخیر، نمودار روند و فعالیت‌های اخیر مدیریت.
- **لینک‌ها:** ساخت لینک و slug، UTM، کمپین، تاریخ/ساعت انقضا، جست‌وجو، فیلتر، مرتب‌سازی و صفحه‌بندی. کادر لینک رهگیری دکمه کپی داخلی دارد. فعال/غیرفعال‌سازی و حذف با تأیید، همراه با حفظ آمار تاریخی.
- **مقصدها:** نسخه‌های ذخیره‌شده، افزودن مقصد و انتخاب صریح مقصد فعال. مقصد قبلی بازنویسی نمی‌شود.
- **کمپین‌ها:** ساخت، تغییر نام، جست‌وجو و بایگانی/بازگردانی. بایگانی، لینک‌های قبلی را خودکار غیرفعال نمی‌کند.
- **تحلیل ترافیک:** فیلتر تاریخ، کمپین و لینک؛ نمودارهای Plotly برای روند روزانه/ساعتی، کمپین، منبع، رسانه، دستگاه، مرورگر، کشور و UTM campaign/content/term؛ مقایسه حداکثر ده لینک.
- **گزارش کلیک‌ها:** جزئیات قابل مرور با صفحه‌بندی cursor؛ بدون IP خام یا HMAC بازدیدکننده. بدون دانلود کل تاریخ در حافظه مرورگر.

## تنظیمات و امنیت

`DASHBOARD_API_URL` آدرس داخلی FastAPI برای ارتباط سرور به سرور است؛ پیش‌فرض `http://127.0.0.1:8000`.
`PUBLIC_BASE_URL` آدرسی است که برای لینک‌های قابل کپی نمایش داده می‌شود. هیچ‌کدام نباید شامل رمز، query یا API key باشند.
کلیدهای `ADMIN_API_KEY` و `REPORT_API_KEY` از محیط یا `.env` در سرور خوانده می‌شوند. رابط به `DATABASE_URL` و `VISITOR_HMAC_KEY` نیاز ندارد و هیچ اتصال مستقیم به دیتابیس ندارد.

کلید در widget، URL، session state مرورگر یا پیام خطا نمایش داده نمی‌شود. پاسخ‌های خطای بک‌اند و خطاهای اتصال قبل از نمایش به پیام فارسی امن تبدیل می‌شوند. درخواست‌های نوشتن خودکار تکرار نمی‌شوند؛ پس از خطای اتصال، ابتدا فهرست را تازه کنید چون ممکن است ثبت در سرور انجام شده باشد.

فایل `.streamlit/config.toml` برنامه را فقط روی `127.0.0.1:8501` قرار می‌دهد و telemetry را خاموش می‌کند. فرم‌های مدیریتی برای کاربر محلی سیستم قابل دسترس‌اند و ورود کاربری مستقلی ندارند. پیش از انتشار برای دیگران، احراز هویت/مجوز مناسب را جلوی **خود Streamlit** قرار دهید؛ کلید API سمت سرور، جایگزین کنترل دسترسی کاربران رابط نیست. `.streamlit/secrets.toml` و `.env` وارد Git نمی‌شوند.

## تاریخ و معنای آمار

انتخابگر تاریخ میلادی است، نه شمسی. روز شروع و پایان انتخاب‌شده بر حسب تهران و شامل هر دو روز هستند؛ کلاینت آن‌ها را به بازه UTC با پایان انحصاری تبدیل می‌کند. سبدهای تجمیع نمودار از API و بر پایه UTC هستند؛ برچسب زمان بر حسب تهران نمایش داده می‌شود. هیچ شمارش یا تشخیص ربات در رابط دوباره پیاده‌سازی نشده است.

«بازدیدکننده‌ـروز» برآورد روزانه UTC است و تعداد افراد یکتای چندروز نیست. انسان/ربات از قواعد فعلی بک‌اند می‌آید و تخمینی است. کشور ناشناخته به‌درستی «نامشخص» نمایش داده می‌شود. گزارش‌های خارج از مدت نگهداری خام می‌توانند ناقص باشند و پیام هشدار دارند.

## حدود صفحه‌بندی

فهرست مدیریت ۲۵ مورد در هر صفحه، جزئیات کلیک ۱۰۰ مورد، گزینه‌های انتخابگر حداکثر ۵۰۰ نتیجه جست‌وجو، گروه‌های نمودار حداکثر ۲۰ گروه پرترافیک و روند حداکثر ۱۰۰۰ سبد دارد. محدودیت‌ها در رابط اعلام می‌شوند؛ برای نتایج بیشتر، فیلتر/جست‌وجو را دقیق‌تر کنید. مرتب‌سازی ستون جدول فقط روی صفحه فعلی است؛ مرتب‌سازی کل فهرست لینک‌ها از انتخابگر مربوطه به API ارسال می‌شود.

تغییر کمپین یک لینک، رخدادهای تاریخی آن را تغییر نمی‌دهد. برای گزارش تاریخی، لینک‌ها فقط بر اساس مالکیت فعلی در کمپین محدود نشده‌اند. زمان انقضای قبلی در ویرایش نامرتبط با تمام دقت قبلی حفظ می‌شود؛ انتخاب زمان جدید با دقت دقیقه است.

## معماری و توسعه

| فایل | مسئولیت |
|---|---|
| `streamlit_app.py` | نقطه شروع Streamlit |
| `dashboard/api.py` | تنظیمات مستقل، HTTP احراز‌شده و خطای امن |
| `dashboard/app.py` | صفحات، فرم‌ها و جریان تعامل |
| `dashboard/presentation.py` | قالب‌بندی زمان/متن و نمودارها |
| `.streamlit/config.toml` | پوسته و تنظیمات محلی |
| `app/links.py` | شمارش، فیلترها و نمای کلی مدیریت؛ پاسخ فهرست‌های قبلی حفظ شده |
| `app/reporting.py` | سه بُعد UTM جدید، با همان منطق قبلی شمارش |

بک‌اند، جدول‌ها، ریدایرکت، worker و endpointهای صادرات قبلی حفظ شده‌اند. هیچ integration جدید Power BI اضافه نشده و داشبورد وابستگی‌ای به آن ندارد. مسیرهای صادرات قبلی برای سازگاری API باقی مانده‌اند.

وابستگی‌های Streamlit/Plotly در extra اختیاری `dashboard` هستند؛ نصب فقط بک‌اند با `requirements.lock` همچنان ممکن است. برای تست کامل از `requirements-dev.lock` استفاده کنید. برای قفل‌کردن وابستگی‌ها:

```bash
uv sync --frozen --extra dashboard
uv export --frozen --no-dev --no-emit-project --format requirements-txt --output-file requirements.lock
uv export --frozen --extra dashboard --no-dev --no-emit-project --format requirements-txt --output-file requirements-dashboard.lock
uv export --frozen --extra dashboard --no-emit-project --format requirements-txt --output-file requirements-dev.lock
```

Dockerfile فعلی همچنان ایمیج بک‌اند است. انتقال رابط به سرور و انتخاب supervisor یا کانتینر جدا، بعد از بررسی سرور انجام می‌شود.
